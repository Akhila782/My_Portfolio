# Portfolio Website - Akhila Nakerekanti

A completely custom-built, lightweight, and modern static portfolio website designed with a Deep Teal and Coral color palette. 

The website uses responsive layouts (CSS Grid and Flexbox) to render beautifully on any screen size.

## Features
- **Frontend:** Completely hand-written, framework-free CSS using variables and responsive media queries.
- **Sections:** Hero, About, Core Competencies, Skills, Experience timeline, Education, and Certifications.
- **Hosting:** 100% static, optimized for instant global CDN hosting (like Vercel, Netlify, or GitHub Pages).

## Quick Deployment on Vercel

Since this is a fully static website, deploying to Vercel takes only a few seconds:

1. **Push to GitHub**:
   Ensure `Home.html`, `vercel.json`, and the `static/` folder are committed to your GitHub repository.
2. **Import to Vercel**:
   Log in to [Vercel](https://vercel.com/), click **Add New...** -> **Project**, and import your repository.
3. **Deploy**:
   Vercel automatically detects the static configuration. Just click **Deploy**!
